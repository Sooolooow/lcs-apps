# Low's Custom Stainless — Apps

Live tools for the shop. Each folder is a standalone app, deployed on Vercel.

| App | Path | Purpose |
|---|---|---|
| Quote Calculator | `/quote-calculator/` | Instant ballpark from part type, dims, material, gauge, finish, edge, rail |
| Job Tracker | `/job-tracker/` | Pipeline from quote → fab → ship → install → done |
| Material Estimator | `/material-estimator/` | Sheet count, weight, scrap before cutting |
| Weight Calculator | `/weight-calculator/` | Plate, sheet, tube, pipe, bar stock — lb & kg |
| TIG Weld Guide | `/weld-guide/` | 304/316L butt & fillet amps, tungsten, gas, passes |
| Install Checklist | `/install-checklist/` | Field-ready zero-disruption checklist by phase + photo capture |
| Warranty Tracker | `/warranty-tracker/` | One-year workmanship log, expiry, claims |
| Photo Gallery | `/photo-gallery/` | Filterable project gallery by type |

Built for NEWEN. Deployed from `Sooolooow/lcs-apps`.
